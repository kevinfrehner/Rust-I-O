# Rust Text File Analyzer

Using Rust and its standard libraries, I created a text file analyzer that reads text from an input file and converts all text to uppercase, counts the number of characters, words, and lines, identifies the most frequently used word, and writes the results to an output file.

## Instructions for Build and Use

### Steps to build and/or run the software:

* Install Rust and Cargo.
* Create a Rust project and place the source code in `src/main.rs`.
* Add an `input.txt` file to the project directory.
* Open a terminal in the project folder.
* Run the following command:

```bash
cargo run
```

* The program will create an `output.txt` file containing the results.

### Instructions for using the software:

* Open the `input.txt` file.
* Enter the text you want to analyze.
* Save the file.
* Run the program using Cargo.
* Open `output.txt` to view the generated report.
